# Exercício: Operações Matemáticas e Calculadora em Python
## Descrição

** Este exercício tem como objetivo praticar a manipulação de variáveis numéricas e operações matemáticas em Python., durante a atividade, foram declaradas duas variáveis numéricas, realizadas conversões de tipo, aplicadas operações aritméticas básicas e, por fim, desenvolvida uma calculadora simples para o usuário interagir.**

## Etapas do Exercício

1. Declaração de Variáveis:
Foram criadas duas variáveis numéricas com valores iniciais diferentes.

2. Conversão de Tipos:
Cada variável teve seu tipo trocado — por exemplo, de int para float, e vice-versa — para praticar conversões entre tipos numéricos.

2. Operações Matemáticas:
Foram aplicadas quatro operações básicas:

1. Adição (+)

2. Subtração (-)

3. Multiplicação (*)

4. Divisão (/)

## Criação de uma Calculadora:
**Ao final, foi implementada uma calculadora simples que:**

* Solicita dois números do usuário;

* Pede a operação desejada;

* Exibe o resultado formatado na tela.

## Conceitos Praticados

* Declaração de variáveis

* Conversão de tipos (int(), float())

* Operadores aritméticos

* Entrada e saída de dados (input(), print())
